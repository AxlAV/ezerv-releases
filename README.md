# Ezerv — releases

Instaladores de **Ezerv**, el panel para crear y administrar servers de juego (Minecraft y más)
desde tu PC, con acceso remoto seguro para tus amigos.

Este repositorio **solo contiene los instaladores** publicados. La app de escritorio lo consulta
para actualizarse sola.

## Instalar

1. Descarga `Ezerv-Setup-<versión>.exe` desde [Releases](../../releases/latest).
2. Ejecútalo. Windows SmartScreen puede advertir porque el instalador todavía no tiene firma de
   código: elige **Más información → Ejecutar de todas formas**.
3. Si te invitaron, abre el enlace `ezerv://join?...` (o pega el código en «Tengo una invitación»).

## Verificar la descarga

Cada release incluye `latest.yml` con el SHA-512 del instalador; la app lo comprueba antes de
aplicar una actualización.
